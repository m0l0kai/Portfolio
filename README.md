**Технологии:** Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly.

### Алгоритм детектирования текстовых областей на изображениях

Алгоритм компьютерного зрения для локализации текстовых областей на изображениях со сложным фоном и визуальными помехами.

- Предварительная обработка изображений.
- Выделение устойчивых текстовых регионов с помощью MSER.
- Геометрическая фильтрация и морфологическое объединение символов.
- Разделение объединённых текстовых областей и сегментация символов.

Алгоритм реализован на основе классических методов компьютерного зрения без использования нейросетевого детектора.

**Результаты тестирования:**
- Precision — 90,47%
- Recall — 94,24%
- F1-Score — 92,30%

**Технологии:** Python, OpenCV, NumPy, MSER.

### Система поиска, распознавания и перевода текста на изображении

Программный комплекс для интерактивного поиска, распознавания и перевода текста на графических изображениях. Работает как экранный переводчик: пользователь выбирает область изображения, система обнаруживает и распознаёт текст, переводит его на русский язык и отображает результат поверх исходного изображения.

- Детекция текста на основе MSER.
- Геометрическая фильтрация и постобработка текстовых регионов.
- Распознавание с помощью EasyOCR.
- Машинный перевод через библиотеку translators.
- Графический интерфейс с экранным оверлеем.

**Результаты тестирования:** система набрала 51 балл из 60 возможных по результатам проверки на 30 экранах. Сквозная эффективность составила **85%**.

**Технологии:** Python 3.11, OpenCV, NumPy, EasyOCR, translators, PySide6.

### Реляционная база данных для управления финансовыми операциями малого бизнеса

База данных и пользовательское приложение в среде Microsoft Access для учёта и анализа финансовых операций малого бизнеса. Система позволяет работать с контрагентами, счетами, товарами, ценами поставщиков и операциями, а также формировать сводные отчёты по клиентам, поставщикам и прибыли.

- Проектирование реляционной структуры данных.
- Разработка пользовательских форм для работы с данными.
- Создание SQL-запросов для выборки и анализа информации.
- Формирование отчётов по финансовым операциям, клиентам, поставщикам и марже.
- Приведение структуры базы данных к третьей нормальной форме (3НФ).

**Технологии:** Microsoft Access, SQL.
