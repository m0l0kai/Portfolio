# Реляционная база данных для управления финансовыми операциями малого бизнеса

База данных и пользовательское приложение в среде Microsoft Access для учета и анализа финансовых операций малого бизнеса. Система позволяет работать с контрагентами, счетами, товарами, ценами поставщиков и операциями, а также формировать сводные отчеты по клиентам, поставщикам и прибыли. Для обработки данных используются SQL-запросы. Исходный файл базы данных и учебные данные не размещены в открытом доступе.

Основные компоненты:

- Реляционная база данных на платформе Microsoft Access
- Пользовательские формы для добавления, просмотра, редактирования и удаления данных
- Система SQL-запросов для выборки и анализа информации
- Схема связей между таблицами
- Отчеты по финансовым операциям, клиентам, поставщикам и марже

Функциональные возможности:

- Учет контрагентов, счетов, товаров, операций и цен поставщиков
- Добавление, изменение и удаление заказов и данных о контрагентах
- Просмотр истории заказов клиентов и прайс-листов поставщиков
- Формирование журнала операций и отчетов по счетам клиентов
- Анализ закупок у поставщиков и расчет маржи
- Выполнение многотабличных SQL-запросов с фильтрацией, сортировкой, объединением и агрегатными функциями

Технологии: Microsoft Access, SQL

Структура базы данных приведена к третьей нормальной форме (3НФ).
