# Алгоритм детектирования текстовых областей на изображениях

Проект представляет собой алгоритм компьютерного зрения для локализации текстовых областей на изображениях со сложным фоном и визуальными помехами. Детектор работает в выбранной области интереса, выполняет предварительную обработку изображения, выделяет устойчивые текстовые регионы с помощью MSER, объединяет отдельные символы в текстовые блоки и при необходимости разделяет объединённые области на отдельные символы. Результат может использоваться как подготовительный этап перед OCR (Optical Character Recognition).

Тестирование детектора: 30 изображений, 1128 текстовых символов. Precision: 90,47%, Recall: 94,24%, F1-Score: 92,31%.

Основной алгоритм: предобработка изображения → MSER → геометрическая фильтрация → морфологическое объединение символов → разделение объединённых текстовых областей → сегментация символов.

Алгоритм реализован на основе классических методов компьютерного зрения без использования нейросетевого детектора.

Технологии: Python, OpenCV, NumPy, MSER
