# Прогнозирование спроса и выявление факторов, влияющих на продажи

Проект по анализу и прогнозированию объёма продаж алкогольной продукции на основе исторических данных Iowa Liquor Sales. Выполнена предобработка данных, исследование временного ряда и подготовка недельных данных для машинного обучения. Реализованы базовые методы прогнозирования, модель случайного леса (Random Forest) и линейная регрессия. Проведено сравнение качества моделей с использованием MAE, RMSE и среднего смещения прогноза (MSD). Выполнен анализ важности признаков для оценки их вклада в прогнозирование.

Технологии: Python, Pandas, NumPy, Matplotlib, Scikit-learn, Jupyter Notebook.
