# Система поиска, распознавания и перевода текста на изображении

Программный комплекс для интерактивного поиска, распознавания и перевода текста на графических изображениях. Система работает как экранный переводчик: пользователь выбирает область изображения, после чего детектор находит текстовые области, OCR-модуль распознаёт текст, а модуль перевода преобразует полученный текст на русский язык и отображает результат поверх исходного изображения.

Основные компоненты: детекция текста на основе MSER, геометрическая фильтрация и постобработка текстовых регионов, распознавание с помощью EasyOCR, машинный перевод через библиотеку translators и графический интерфейс с экранным оверлеем.

Тестирование системы проведено на 30 изображениях. Сквозная эффективность - 85%.

Технологии: Python 3.11, OpenCV, NumPy, EasyOCR, translators, PySide6

Детектор текста реализован на основе классических методов компьютерного зрения без использования нейросетевого детектора. Архитектура системы позволяет заменять отдельные компоненты без изменения остальных модулей.

## Запуск

Требуется Python 3.11.

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите основной файл проекта:

```bash
python main.py
```

Для Windows при необходимости Python и зависимости следует устанавливать в окружение проекта.
